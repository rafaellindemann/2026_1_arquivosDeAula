▸ api-conceitos / v1
REST API · JSON · Node.js + Express

Base de Conceitos
de Testes de Software

Uma API RESTful para explorar, pesquisar e revisar conceitos fundamentais sobre testes de software — de tipos e níveis até práticas e técnicas.

O que essa API faz
📚

Conceitos estruturados

Cada item possui código, categoria, descrição, palavras-chave, exemplos e conceitos relacionados.

🔗

Conceitos relacionados

Cada conceito aponta para outros por código. Clique em um número para navegar direto ao conceito.

⚡

CRUD completo

Suporte a GET, POST, PUT, PATCH e DELETE. Persistência em arquivo JSON local.

🎯

Sem banco de dados

Dados armazenados em data.json — simples, portátil e fácil de editar.

Endpoints disponíveis
GET /items Lista todos os conceitos
GET /items/:id Busca um conceito pelo ID
POST /items Cria um novo conceito
PUT /items/:id Substitui completamente um conceito
PATCH /items/:id Atualiza parcialmente um conceito
DELETE /items/:id Remove um conceito
