Crie um frontend vanilla para consumir este backend e mostrar os conceitos relacionados a testes de software.

Esse front deve ser clean e responsivo e ter 4 páginas:
- Home, expplicando o que ele faz (quase um readme);
- Geral, que mostra todos os conceitos armazenados no json;
- Pesquisa, que permite ao usuário pesquisar por um termo e ver os conceitos que batem com aquele termo;
- Random, mostra um conceito aleatório.

No item de relacionados, se clicar no número de um conceito deve redirecionar para esse conceito.

./src/server.js e data.json no anexo.
