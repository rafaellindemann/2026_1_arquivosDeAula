Operadores são símbolos especiais que dizem ao computador o que fazer: somar números, comparar valores, tomar decisões e muito mais. Sem eles, o código não faz nada de útil!

Operadores Aritméticos

Fazem cálculos matemáticos com números — igual à calculadora!

+
Adição
Soma dois valores. O mais básico de todos!
let total = 5 + 3; // total = 8
✅ Resultado: 8
−
Subtração
Subtrai um valor do outro. Simples assim!
let resto = 10 - 4; // resto = 6
✅ Resultado: 6
*
Multiplicação
Multiplica dois valores.
let area = 6 * 7; // area = 42
✅ Resultado: 42
/
Divisão
Divide um valor pelo outro. Pode retornar decimais!
let metade = 9 / 2; // metade = 4.5
✅ Resultado: 4.5
%
Módulo (Resto)
Retorna o resto da divisão. Super útil para saber se um número é par ou ímpar!
10 % 3 // → 1 8 % 2 // → 0 (par!)
✅ 10 ÷ 3 = 3 com resto 1
**
Exponenciação
Eleva um número à potência de outro. Dois asteriscos!
2 ** 8 // 2⁸ = 256 3 ** 3 // 3³ = 27
✅ 2⁸ = 256
++
Incremento
Adiciona 1 à variável. Atalho para x = x + 1.
let x = 5; x++; // x agora é 6
✅ x vai de 5 para 6
−−
Decremento
Subtrai 1 da variável. Atalho para x = x - 1.
let x = 10; x--; // x agora é 9
✅ x vai de 10 para 9
=

Operadores de Atribuição

Guardam (atribuem) valores dentro de variáveis. O = é o mais importante de todos!

=
Atribuição simples
Guarda um valor numa variável. Não é "igual a" — é "recebe"!
let nome = "Ana"; let idade = 16;
✅ nome recebe "Ana"
+=
Atribuição com adição
Soma e já guarda. x += 5 é igual a x = x + 5.
let pontos = 10; pontos += 5; // pontos = 15
✅ pontos vai de 10 para 15
−=
Atribuição com subtração
Subtrai e já guarda. x -= 3 é igual a x = x - 3.
let vida = 100; vida -= 20; // vida = 80
✅ vida vai de 100 para 80
*=
Atribuição com multiplicação
Multiplica e guarda. x *= 2 dobra o valor de x.
let preco = 50; preco *= 2; // preco = 100
✅ preco vai de 50 para 100
/=
Atribuição com divisão
Divide e guarda. x /= 2 corta o valor na metade.
let fatia = 80; fatia /= 4; // fatia = 20
✅ fatia vai de 80 para 20
%=
Atribuição com módulo
Calcula o resto e guarda.
let n = 17; n %= 5; // n = 2 (resto de 17÷5)
✅ n vai de 17 para 2
**=
Atribuição com potência
Eleva à potência e guarda.
let base = 3; base **= 3; // base = 27 (3³)
✅ 3³ = 27
==

Operadores de Comparação

Comparam dois valores e sempre retornam true (verdadeiro) ou false (falso).

==
Igualdade solta
Verifica se os valores são iguais, mas ignora o tipo. Pode causar surpresas!
5 == "5" // true 😮 0 == false // true 😮
⚠️ Cuidado com a conversão automática!
===
Igualdade estrita
Verifica valor E tipo. Muito mais seguro! Use este na maioria das vezes.
5 === "5" // false ✅ 5 === 5 // true ✅
✅ Prefira sempre o ===
!=
Diferente solto
Verifica se são diferentes, mas ignora o tipo (mesmo problema do ==).
5 != "5" // false 😮 5 != 6 // true
✅ Resultado: false, true
!==
Diferente estrito
Verifica se são diferentes em valor E tipo. Use este!
5 !== "5" // true ✅ 5 !== 5 // false ✅
✅ Resultado: true, false
>
Maior que
Verdadeiro se o valor da esquerda for maior.
10 > 5 // true 3 > 7 // false
✅ Resultado: true, false
<
Menor que
Verdadeiro se o valor da esquerda for menor.
3 < 7 // true 10 < 5 // false
✅ Resultado: true, false
>=
Maior ou igual
Verdadeiro se for maior ou igual.
18 >= 18 // true 17 >= 18 // false
✅ Útil para verificar idade mínima!
<=
Menor ou igual
Verdadeiro se for menor ou igual.
5 <= 10 // true 10 <= 5 // false
✅ Resultado: true, false
&&

Operadores Lógicos

Combinam condições para tomar decisões mais complexas no código.

&&
E (AND)
Verdadeiro somente se as duas condições forem verdadeiras. "Precisa das duas coisas".
let idade = 20; let temCNH = true; idade >= 18 && temCNH // true && true → true ✅
✅ Pode dirigir: true
||
OU (OR)
Verdadeiro se pelo menos uma condição for verdadeira. "Qualquer uma serve".
let temDinheiro = false; let temCartao = true; temDinheiro || temCartao // false || true → true ✅
✅ Pode pagar: true
!
NÃO (NOT)
Inverte o valor lógico. O que é verdadeiro vira falso, e vice-versa.
!true // → false !false // → true let logado = false; !logado // → true (não logado)
✅ Inverte a condição
"+"

Operador de Concatenação

O + não serve só para somar! Com textos (strings), ele une os valores.

+
Concatenação de strings
Quando o + encontra textos, ele os junta em vez de somar.
let primeiro = "Olá, "; let segundo = "mundo!"; primeiro + segundo // "Olá, mundo!"
✅ Resultado: "Olá, mundo!"
` `
Template Literals (recomendado!)
Usando crase, você pode colocar variáveis dentro do texto com ${'$'}{variavel}. Muito mais fácil!
let nome = "Carlos"; let idade = 17; `Olá, ${nome}! Você tem ${idade} anos.` // "Olá, Carlos! Você tem 17 anos."
✅ Resultado: "Olá, Carlos! Você tem 17 anos."
+
Número + String = Surpresa!
Quando você mistura número com texto, o JavaScript converte o número pra texto. Fique atento!
5 + "3" // "53" 😮 (não 8!) "Nota: " + 10 // "Nota: 10" ✅
⚠️ Misturar tipos pode gerar resultados inesperados!
?:

Operador Ternário

Um if/else em uma só linha! Muito usado para decisões rápidas.

? :
Operador ternário (condicional)
A estrutura é:

condição ? se_verdadeiro : se_falso

Pense assim: o ? é o "então" e o : é o "senão".
let idade = 17; let msg = idade >= 18 ? "Pode entrar! 🎉" : "Menor de idade 🚫"; // msg = "Menor de idade 🚫"
✅ msg = "Menor de idade 🚫"
?

Operadores de Tipo

Descobrem o tipo de um valor ou se um objeto é de certo tipo.

typeof
Tipo do valor
Retorna uma string dizendo qual é o tipo do valor: "number", "string", "boolean", etc.
typeof 42 // "number" typeof "Oi" // "string" typeof true // "boolean" typeof undefined // "undefined" typeof [] // "object" 😮
✅ Descobre o tipo em tempo real
instanceof
Instância de
Verifica se um valor foi criado a partir de um determinado "molde" (classe/construtor). Retorna true ou false.
let lista = [1, 2, 3]; let hoje = new Date(); lista instanceof Array // true hoje instanceof Date // true lista instanceof Date // false
✅ Útil para verificar tipos de objetos
...

Spread e Rest ( ... )

Os três pontinhos fazem coisas diferentes dependendo de onde aparecem!

...
Spread — "Espalhar"
Espalha os itens de um array ou objeto. Usado na chamada de funções ou para copiar/combinar arrays.
let frutas = ["🍎", "🍌"]; let mais = ["🍇", ...frutas, "🍊"]; // ["🍇","🍎","🍌","🍊"] Math.max(...[3, 1, 9, 2]) // 9
✅ Expande o array no lugar
...
Rest — "Juntar o resto"
Na declaração de uma função, junta todos os argumentos extras em um array.
function somar(...nums) { return nums.reduce((a,b) => a+b, 0); } somar(1, 2, 3, 4) // 10 somar(5, 10) // 15
✅ Aceita qualquer quantidade de argumentos
...
A diferença em resumo
Spread → você está chamando algo e quer expandir.

Rest → você está definindo algo e quer agrupar.

Mesma sintaxe, usos opostos!
// SPREAD: expande ao chamar Math.min(...[4,2,8]) // 2 // REST: agrupa ao definir function f(...args) { ... }
✅ Contexto define o comportamento
?.

Encadeamento Opcional e Coalescência Nula

Dois operadores modernos que evitam erros ao trabalhar com valores que podem não existir.

?.
Encadeamento opcional
Acessa uma propriedade ou método sem quebrar o código se o objeto for null ou undefined. Retorna undefined ao invés de dar erro.
let user = null; // Sem ?. → ERRO! 💥 user.nome // TypeError! // Com ?. → Seguro ✅ user?.nome // undefined let p = { endereco: { cidade: "SP" } }; p?.endereco?.cidade // "SP" p?.telefone?.ddd // undefined
✅ Evita o famoso TypeError!
??
Coalescência nula (Nullish)
Retorna o valor da direita apenas se o da esquerda for null ou undefined. Diferente do || que rejeita também 0 e "".
let nome = null; nome ?? "Visitante" // "Visitante" let pontos = 0; pontos ?? 100 // 0 ✅ (0 é válido!) pontos || 100 // 100 😮 (|| trata 0 como falso)
✅ Mais preciso que o || para valores padrão
&

Operadores Bitwise

Trabalham diretamente com os bits dos números. São avançados — você não vai precisar deles no início!

⚡ Avançado
&
AND bit a bit
Compara cada bit dos dois números. O resultado é 1 só onde ambos têm 1.
5 & 3 // 101 & 011 = 001 → 1
✅ 5 & 3 = 1
⚡ Avançado
|
OR bit a bit
O resultado é 1 onde pelo menos um dos bits é 1.
5 | 3 // 101 | 011 = 111 → 7
✅ 5 | 3 = 7
⚡ Avançado
^
XOR bit a bit
O resultado é 1 onde os bits são diferentes entre si.
5 ^ 3 // 101 ^ 011 = 110 → 6
✅ 5 ^ 3 = 6
⚡ Avançado
~
NOT bit a bit
Inverte todos os bits do número. Resulta em -(n+1).
~5 // -6 ~0 // -1
✅ ~5 = -6
⚡ Avançado
<<
Deslocamento à esquerda
Move os bits para a esquerda. Equivale a multiplicar por 2ⁿ.
1 << 3 // 1×2³ = 8 5 << 1 // 5×2¹ = 10
✅ 1 << 3 = 8
⚡ Avançado
>>
Deslocamento à direita
Move os bits para a direita. Equivale a dividir por 2ⁿ (inteiro).
8 >> 2 // 8÷4 = 2 16 >> 1 // 16÷2 = 8
✅ 8 >> 2 = 2
⚡ Avançado
>>>
Deslocamento sem sinal
Igual ao >> mas sempre preenche com zeros (nunca negativo). Raramente usado no dia a dia.
-1 >>> 0 // 4294967295 (número gigante!)
✅ Resultado: 4294967295
