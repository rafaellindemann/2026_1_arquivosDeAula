Operadores JS

Os blocos de construção da lógica. Use-os para calcular, comparar e tomar decisões no seu código.

Aritméticos

Usados para realizar contas matemáticas básicas.

+
Adição
Soma dois valores.
10 + 5
// Resultado: 15
**
Exponenciação
Eleva um número à potência de outro.
2 ** 3
// Resultado: 8
%
Módulo
Retorna o resto da divisão.
10 % 3
// Resultado: 1
++ / --
Incremento / Decremento
Adiciona ou subtrai 1.
let x = 5; x++;
// Resultado: 6

Comparação

Sempre retornam um valor booleano: true ou false.

==
Igualdade Amigável
Compara o valor, mas ignora o tipo.
5 == "5"
// Resultado: true
===
Igualdade Estrita
Compara valor E tipo (Recomendado).
5 === "5"
// Resultado: false
!==
Não Idêntico
Verifica se são diferentes em valor ou tipo.
10 !== 10
// Resultado: false

Lógicos

Usados para combinar condições.

&&
E (AND)
Retorna verdadeiro se AMBOS forem verdade.
(5>2) && (10<20)
// Resultado: true
||
OU (OR)
Verdadeiro se PELO MENOS UM for verdade.
(5<2) || (10<20)
// Resultado: true
!
NÃO (NOT)
Inverte o estado lógico.
!true
// Resultado: false

Propagação e Resto (...)

...
Spread (Espalhar)
Expande elementos de um array ou objeto.
const novo = [...velho, 4];
// Copia e adiciona
...
Rest (Resto)
Agrupa vários argumentos em um array.
function(a, ...resto)
// Coleta o que sobrou

Modernos & Nulidade

?.
Encadeamento Opcional
Lê propriedades sem erro se o objeto for null.
usuario?.endereco?.rua
// Retorna undefined, não erro
??
Coalescência Nula
Retorna o lado direito se o esquerdo for null/undefined.
nome ?? "Anônimo"
// Fallback seguro

Bitwise Avançado

Trabalham diretamente com os bits (0 e 1) dos números. Usados em performance extrema ou criptografia.

& | ^ ~
Operadores de Bit
AND, OR, XOR e NOT binários.
5 & 1 (0101 & 0001)
// Resultado: 1
